# Public Stance

Azazeleous is being established as a public-facing representative of a larger documented system whose private source history, technical lineage, and operational records remain separately governed.

Public material may include:
- verified architecture summaries;
- non-sensitive source lineage;
- selected code and reproducible build material;
- research notes cleared for publication;
- public entity descriptions;
- release manifests and integrity hashes.

Public material must not include:
- API keys, tokens, passwords, recovery codes, private keys, or certificates;
- raw personal identifiers;
- full device serials, MAC addresses, IMEIs, or account recovery data;
- private network secrets;
- unreviewed private correspondence;
- raw telemetry that identifies household members or unrelated devices.

The public layer is derived from the private canonical lineage; it is not the canonical lineage itself.
