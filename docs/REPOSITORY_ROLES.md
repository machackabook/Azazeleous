# Repository Roles

## Azazeleous

Private final-draft environment for reviewed ADAM architecture, durable project memory, financial orchestration specifications, and release candidates.

## machackabook repositories

Development, experimentation, integration, and test-bed environment. Changes are promoted only after evidence-backed review.

## Sentinel

Provenance and append-only audit evidence.

## NEXUS / Nexus_Core

Protocol/core architecture and shared runtime concepts.

## Other repositories

Remain independently classified until evidence establishes whether they are active, archival, derivative, upstream, or disposable. Empty repositories are not automatically deleted or privatized by naming convention alone.

## Promotion rule

No artifact becomes canonical merely because it appears in a conversation. It becomes canonical after source identification, repository placement, validation, and review.
